# Sendmonee Clone

A clone of Sendmonee, a money transfer and marketplace platform with multi-currency support.

## Overview

Sendmonee Clone replicates a modern fintech and marketplace platform. It features multiple pages for different services including international wire transfers, marketplace, and FAQ sections.

## Pages

- Home (`index.html`) - Main landing page
- Marketplace (`marketplace.html`) - Product marketplace
- Wire Transfer (`wire.html`) - International money transfer
- About (`about.html`) - Platform information
- FAQ (`faq.html`) - Frequently asked questions

## Technologies

- HTML5
- CSS3 (Responsive design, Flexbox)
- Mobile-first approach
- Flag icons for country selection

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Navigate through different services

## Features

- Multi-page platform
- Marketplace for buying/selling
- International wire transfer interface
- Responsive mobile design
- FAQ section with collapsible answers
- Country selection with flags
- Modern fintech UI

All modern browsers (Chrome, Firefox, Safari, Edge)
